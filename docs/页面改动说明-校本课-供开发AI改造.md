# 校本课 V0.8.5 · 页面改动说明（供开发 / AI 改造用）

> 用途：对照「空中课堂 · 混排课」存量代码做改造。  
> 基线：混排课现有实现；本文只写**相对混排课的差异**与**本期新增**。  
> 原型对照：`prototype/`（教务 / 教师 / 学生 PAD）  
> 版本：V0.8.5｜整理自原型内「改 N / 新增 N」说明

---

## 使用说明（给开发 / AI）

1. 按 **角色 → 模块 → 页面** 定位要改的页。
2. 先读该页的 **页面上游**，确认入口与前置状态。
3. 再按 **改动清单 / 新增清单** 改代码；未写明的能力默认**与混排课保持一致**。
4. 「改 N」「新增 N」与原型页蓝/橙角标编号一致，便于对照原型。
5. 文档顺序：教师 → 教务·课程库 → 教务·课程管理 → 学生 PAD。

**改动清单**

- （本处以新增为主；弹窗其余能力未单独列出的，默认与混排课一致）
