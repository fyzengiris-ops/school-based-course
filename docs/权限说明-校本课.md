# 校本课权限说明

校本课是学校自己维护、发给学生自学的资源，和空中课堂点播课分开。学生能不能看到一门资源包，由学习名单和开通设备决定，不由学生自己申请。

权限说明区分两个版本，分别是V0.9和V1.0

V0.9是已经确定的需求部分；

V1.0是还在设计中的部分，需求未定稿，开发时，只是做好预期管理

# V0.9

> 状态：需求已定，供本期开发。

本期只做一条链路：教师上传单资源，教务审核，教务发布资源包，学生查看已发布的资源包。

下面这些不在 V0.9，写在后文 V1.0，本期不要做：

- 教师端：
  - 在「我的资源」里把资源分享到校本课；
  - 在校本课里发布资源包
  - 维护自己的学习名单和学情
- 教务端
  - 「教师数据」
- 学生端
  - 按学科查看各学科教师的资源包

## 1. 应用入口怎么显示

「校本课」这个应用入口，先看机构有没有开通。

| 对象 | 怎么显示 |
| --- | --- |
| 没有开通校本课的机构 | 不显示这个应用入口。教务、教师、学生都看不到 |
| 已开通机构的教务、教师 | 入口一直高亮 |
| 已开通机构里，开通了校本课应用的学生 | 入口高亮 |
| 已开通机构里，没有开通校本课应用的学生 | 入口仍在，置灰 |
| 开通了校本课的设备 | 入口高亮 |

学生端入口在 PAD。教务、教师入口在 PC。机构未开通时，这三端都不出现入口。

## 2. 教务、教师、学生核心权限对比

|  | 教务 | 教师 | 学生 |

## 3. 教务

入口：乐课 PC 教务首页 → 校本课。校本课页面左侧是「资源包管理」「资源库」。没有「教师数据」。

### 3.1 可以做

**资源包管理**

- 发布资源包，填写资源包名称、学段学科、总课时数，并设置学习方式、视频进度条、作业批改、封面和简介。
- 给资源包添加目录和资源。资源可以是微课、试卷、课件。微课还可以带配套试卷和课件，并支持预览。放进资源包的单资源，须是审核通过的。
- 对已上架资源包继续添加资源。内容有增删后才能再次发布。
- 修改基本信息。修改时年级学科不可改，名称和总课时数可以改。
- 维护学习名单：按全部名单或自定义名单发放；自定义时可添加本校已开通校本课的学生、按乐号添加、批量导入、移除、导出。可以学习的名单从中台获取，见第 7 节。
- 按学校开通方式决定是否提供「名单学生可学习」「开通设备可学习」。两种都开通时，可以同时勾选。开通设备的数据从中台获取，见第 7 节。
- 下架、删除资源包。资源包下架后，学生端隐藏该资源包，学生不能再查看。
- 查看单个或多个资源包的学习数据，包括学习完成率、作业完成率、视频观看时长占比、课件查看率、课件内容查看率。

**资源库**

- 查看本校老师提交的单资源（视频、试卷、课件）。
- 审核处于「审核中」的单资源，给出通过或不通过。
- 审核通过的单资源可被选进资源包。不提供原点播课系统里的「打包」能力。
- 审核不通过时，可编辑视频名称、学段学科、资源分组，并查看审核记录。
- 移动资源分组。

### 3.2 不能做

- 不设置资源价格、报名、学习有效期、直播和巡课。作业批改只保留学生自批。
- 添加学生时，不能选分层班，也不能把未开通校本课的学生加进来。
- 不维护空中课堂点播课的数据。两边资源、名单、学情互不相通。
- 不配置学校用「按设备」还是「按人员」开通校本课。这一项由中台决定，教务只在开通结果允许时使用对应的名单方式。
- 不查看教师分享汇总。本期没有「教师数据」。

### 3.3 数据范围

教务看的是本校校本课，不限于某一个老师的任课班级。学习名单里的学生，来自本校已开通校本课的学生。名单和开通设备都以中台数据为准，见第 7 节。

## 4. 教师

入口：乐课 PC 老师首页 → 校本课。校本课页面本期只有「资源库」，用来上传单资源、提交审核。没有「资源包管理」，也没有「教师数据」。

「我的资源」里原有的制作、上传能力保持不变。把资源分享到校本课不在本期。

### 4.1 可以做

**校本课 · 资源库**

- 上传并管理可供教务发布资源包选用的单资源。
- 制作视频，或对试卷、课件直接提交。
- 审核不通过时，编辑视频名称、学段学科、资源分组，然后再次提交。
- 审核中可以撤回、删除。
- 查看自己的审核记录。

### 4.2 不能做

- 不能审核单资源。审核是教务的操作。
- 不能发布、修改、下架、删除资源包，也不能维护学习名单。
- 不能查看资源包学情，也不能查看其他老师的分享汇总。
- 不能把资源从「我的资源」分享到校本课。

### 4.3 数据范围

教师在校本课里只能经营自己上传的单资源。审核通过后，由教务选进资源包。

## 5. 学生

入口：学生 PAD 自适应学习首页 → 校本课。  
本期学生不使用 PC 管理端。学生查看的是教务已发布、且自己被允许学习的资源包。

### 5.1 可以做

- 查看自己有权学习的校本课资源包。资源包下架后，该资源包在学生端隐藏，学生不能再查看。
- 按目录学习。可以看微课，打开配套或单独的试卷、课件。
- 按资源包上的学习方式学习：按课时顺序解锁，或自由选择；视频进度条是否允许拖动，以资源包设置为准。
- 完成作业并自行批改。批改完成后可以看答案解析。作答并提交之后，作业才进入作业系统，见第 5.3 节。
- 看到自己的学习进度。继续学习时，从上次学到的位置进入。

### 5.2 什么情况下看得到资源包

学生是否看得到一个资源包，由该资源包的发放方式决定。判断时用的学习名单、开通设备，都取自中台，见第 7 节。

| 发放方式 | 学生侧结果 |
| --- | --- |
| 名单学生可学习，且为全部名单 | 本校已开通校本课、并落在该名单范围内的学生，用自己的账号登录后可以学 |
| 名单学生可学习，且为自定义名单 | 只有被加进该资源包名单的学生可以学 |
| 开通设备可学习 | 学生用自己的账号，登录本校已开通校本课的设备后可以学 |
| 两种方式同时勾选 | 满足名单或设备任一条件即可学 |

这些资源包都由教务发布，面向教务在该包上维护的对象。本期学生端不提供按学科进入某位教师资源包的入口。

资源包下架后，不再按上表展示。该资源包从学生端隐藏，学生不能打开、不能继续查看。

### 5.3 作业何时进入作业系统

视频配套的作业，以及独立的作业资源，走同一条规则：学生在校本课里完成作答并提交后，这份作业才流向作业系统。

点播课原有机制是视频学完后，配套作业就流向作业系统。校本课不用这套时机。校本课同时有配套作业和独立作业，两边进入作业系统的时机要一致，所以统一为作答并提交之后再流转。只看完视频、还没有作答提交的作业，不进入作业系统。

进入作业系统之后，按下面各项显示。和点播课配套作业一致的，按点播课同一套处理；不一致的，按本表执行。

| 显示项    | 校本课怎么显示                                             | 和点播课配套作业       |
| ------ | --------------------------------------------------- | -------------- |
| 作业标题   | 这份作业所属资源包的目录名称                                      | 一致             |
| 作业名称   | 这份作业的试卷名称                                           | 一致             |
| 作业类型   | 分数作业                                                | 一致             |
| 同学提交情况 | 分子是这份作业在这个资源包里被提交的数量，分母是可以学习这个资源包的学生数量              | 一致             |
| 提交状态   | 待批改，或已批改。按这名学生这份试卷的实际状态显示                           | 不一致。校本课没有「未提交」 |
| 得分     | 待批改时为 0；已批改时按学生实际得分显示                               | 一致             |
| 作业学科   | 试卷的学科                                               | 一致             |
| 教师名称   | 教务发布的资源包，显示把这份作业提交到教务资源库的教师名称。教师发布的资源包或资源，显示这个教师的名称 | 不一致            |
| 作业类型   | 校本课作业（本期新增）                                         | 不一致            |
| 开始时间   | 资源被分享到学生端校本课的时间                                     | 一致             |
| 截止时间   | 开始时间加 3 年                                           | 一致             |
| 作业提交时间 | 学生正常提交的时间                                           | 一致             |

作业报告里，原「班级平均分」文案改为「平均分」。计算方式不变：分子是已提交作业的分数之和，分母是该试卷总分乘以已提交人数。

## 6. 角色之间怎么配合

1. 教师在校本课资源库制作单资源并提交。教务审核。
2. 审核通过后，由教务把单资源放进资源包并发布。教师不能自己发布资源包。
3. 教务负责全校资源包，以及全校已开通校本课的学生和设备。学习名单和开通设备与中台对接，见第 7 节。
4. 学生只查看已经上架、且自己被允许学习的资源。资源包下架后，学生端隐藏该资源包。
5. 学生在校本课作答并提交后，作业才进入作业系统。视频学完本身不把作业送进作业系统。
6. 校本课数据与空中课堂点播课隔离。在一边的上传、名单、学情，不自动出现在另一边。

## 7. 与中台对接

学习名单和开通设备都不在校本课里自行维护，需要和其他平台的中台对接。

- 可以学习的名单：获取学习名单、以及这份名单里哪些学生可以学习，都与中台对接。教务维护资源包名单、学生能否看到资源包，都使用这份数据。
- 开通的设备：哪些设备开通了校本课，与中台对接。教务按开通结果使用「开通设备可学习」，学生在已开通设备上学习，也使用这份数据。

校本课不配置学校用「按设备」还是「按人员」开通。开通方式由中台决定。

## 2. 教师在「我的资源」分享资源

入口：乐课 PC 老师首页 →「我的资源」。  
这里原有的制作、上传仍然沿用资源库已有能力。V1.0 新增的是分享到校本课。

方案中的做法：

- 把资源分享到校本课。可以分享单个资源，也可以多个资源一起分享。
- 分享时可以进入已有资源包，也可以新建资源包。新建后，该老师所教班级里已开通校本课的学生，可以学习这个资源包中的资源。
- 每个资源包可以查看当前学习名单。名单要改时，进入校本课修改，不在「我的资源」里改。
- 系统为每位老师生成一个以本人姓名命名的资源包。在「我的资源」里，这个资源包不能改名、不能添加目录、不能删除，只能查看学习名单。

多个资源一起分享时的页面方案（分享应用、存放位置、默认资源包的摆放）还在比较，没有选定最终稿。

## 3. 教师在校本课发布资源包

入口：乐课 PC 老师首页 → 校本课。  
左侧在 V0.9 的「资源库」之外，增加「资源包管理」。仍然没有「教师数据」。

### 3.1 方案中可以做

**资源包管理**

- 发布自己的资源包，添加目录和资源，维护学习名单，查看学习数据。
- 学习名单的筛选是「班级」。添加学生、批量导入时，校验范围是自己所教班级里已开通校本课的学生。
- 对自己创建的普通资源包，可以修改、下架、删除。
- 学习名单默认覆盖所教班级中已开通校本课的学生；需要缩小时，改为自定义名单后再增删。

**系统资源包（以教师姓名命名）**

系统会为每位老师生成一个资源包，名称就是当前老师的姓名。这个资源包：

- 状态始终是已上架。
- 可以添加资源、维护学习名单、看学习数据、进入修改页。
- 修改时，资源包名称不能改。总课时数不能手填，按资源包里的资源条数自动统计。
- 不能下架，不能删除。

### 3.2 方案中仍然不能做

- 不能审核单资源。审核仍是教务的操作。
- 不能查看「教师数据」，也不能查看其他老师的分享汇总。
- 不能把学习名单扩到自己任课范围以外的学生。可选学生仍须已开通校本课。
- 不能改系统资源包的名称，不能手改它的课时数，不能下架或删除它。
- 不配置学校的设备开通方式。教师学习名单上是否保留「开通设备可学习」，还没有定。

### 3.3 数据范围

教师只能经营自己的资源，以及自己所教、已开通校本课的学生。

## 4. 教务端新增教师数据

入口仍是乐课 PC 教务首页 → 校本课。  
左侧在「资源包管理」「资源库」之下增加「教师数据」。

方案中的做法：

- 按教师查看：教师名称、已分享资源数、任教学科数。已分享资源数默认从多到少。点「查看详情」，看这位老师在各学科分别分享了多少。
- 按学科查看：先选定学科，再看该学科下的教师名称和已分享资源数。学科列不重复展示。
- 只查看，不在这里改老师的资源或名单。

统计口径、是否还要其他维度，还没有定稿。

## 5. 学生端新增各学科教师的资源包

入口仍是学生 PAD 自适应学习首页 → 校本课。  
V0.9 已能查看教务发布的资源包。V1.0 打算在此之外，增加各学科教师的资源包。

方案中的做法：

- 学生按学科，看到该学科教师的资源包。其中包括以教师姓名命名的系统资源包，以及教师分享或发布出来的资源包。
- 教师新建并分享的资源包，默认面向该老师所教班级中已开通校本课的学生。
- 学生是否看得到某一个教师资源包，仍由该包的发放方式决定，规则与 V0.9 的名单、设备条件相同。
- 学生仍然不能发布、修改资源包，也不能改学习名单。

学生端如何分开展示「教务发布的资源包」和「各学科教师的资源包」、入口放在哪一级，还没有定稿。

## 6. 和 V0.9 怎么接上

1. 教师上传单资源、教务审核，仍按 V0.9。审核通过前，资源不能因为分享就绕过审核。
2. 审核通过后，除教务可以放进资源包外，教师也可以把资源放进自己的资源包，或从「我的资源」分享进自己的资源包。
3. 教务继续负责全校资源包和全校已开通学生。教师负责自己的资源包和自己的任课学生。
4. 学生一边学习教务已发布且自己被允许的资源包，一边可以进入各学科教师的资源包。资源下架后不能再查看。
5. 校本课与空中课堂点播课仍然隔离。
