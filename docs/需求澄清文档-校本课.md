# 校本课（自习室/校本课）需求澄清文档

> 版本：V0.8.5｜状态：已澄清（待页面细节逐页确认）｜模块暂定名：**自习室/校本课**

---

## 1. 背景与目标

自适应学习系统需向学生提供**学校自行维护的学习资源**。对应地，需给学校提供资源维护能力。

经评估，平台现有「空中课堂 → 点播课」已覆盖大部分维护与使用诉求。本期策略为：

- **复制点播课能力并改造**，而非从零新建；
- 通过**业务线区分**实现数据隔离，避免冲击空中课堂原有业务；
- **场景化权限配置**由其他业务团队实现，本期自适应侧聚焦三端角色页面与流程。

**本期目标：** 打通教务 / 老师 / 学生三端「维护 + 使用」整套能力（需求清单内均需落地）。

---

## 2. 本期范围

### 2.1 在范围内


| 端   | 角色  | 内容                                          |
| --- | --- | ------------------------------------------- |
| PC  | 教务  | 首页新增「自习室/校本课」入口；资源搭建、选用老师视频、对象分发、学情查看       |
| PC  | 老师  | 首页新增「自习室/校本课」入口；上传视频供教务选用；学情相关能力（与点播课对齐的部分） |
| PAD | 学生  | 首页入口调整后进入校本资源学习；目录结构内资源使用与学习数据呈现            |


能力对齐点播课已有能力（本期需实现，页面按点播课改造呈现）：

- 资源维护：目录结构；视频 / 试卷 / 课件等
- 学习模式控制：进度解锁、自由选择、按时序解锁、进度条锁定等（与点播课一致）
- 作业批改：系统批改 & 学生自主批改
- 对象学生：行政班、分层班、指定学生等
- 学习数据：学生个体进度、视频维度进度等



### 2.2 不在本期（由其他团队 / 后续）

- **场景类型配置的后台实现**（场景①自习室设备可用 / ②学生平板账号可用 / ③账号不可用关闭）——其他业务团队；
- **与点播课底层技术复用细节**（复制改造 / 业务线隔离的代码方案）——开发阶段处理；产品侧要求：**数据与空中课堂点播课隔离**

---



## 3. 角色与职责



### 3.1 教务（PC）

- 入口：乐课 PC 教务首页 → 教学应用区新增 **自习室/校本课**
- 搭建资源：名称、场景（若页面展示）、学科、对象用户（行政班 / 分层班 / 指定学生）
- 可选用老师已上传的视频
- 数据：资源数量、总播放量、学生学习进度等



### 3.2 老师（PC）

- 入口：乐课 PC 老师首页模块区新增 **自习室/校本课**
- 上传视频资源，供教务选用
- **自建资源：待定**（不作为本期验收项）
- 其余页内操作以原型页面为准



### 3.3 学生（PAD · 自适应学习首页）

- **课程中心** → 改名为 **精选资源**（原小节/章节等内容不变）
- **精选卷** → 改名为 **自习室/校本课**（承载学校下发的校本资源）
- 进入后按目录学习资源（对齐点播课学习侧能力）

---



## 4. 预期效果（产品诉求摘要）

1. 资源可按自定义群体分发，或按行政班分发（两种方式）
2. 维护能力、学习数据能力与点播课相近（目录 + 个体学情）
3. 对外体现为独立业务线模块，不与空中课堂点播课数据混用
