# 校本课原型框架

## 打开方式

在本目录启动本地服务后浏览器访问（推荐）：

```bash
npx serve -l 5173 .
```

打开：http://localhost:5173/

也可直接用浏览器打开 `index.html`（部分浏览器对本地图片路径有限制，优先用本地服务）。

## 怎么用

| 操作 | 说明 |
|------|------|
| 顶栏 **PC 端 / PAD 端** | 切换终端 |
| PC 右上角姓名热区 | 下拉切换 **老师 / 教务** 首页截图 |
| PC 青绿虚线 **自习室/校本课** | 进入模块占位页 |
| PAD 右下角标签 | **精选资源**（原课程中心）、**自习室/校本课**（原精选卷） |

PAD 画幅固定为常规平板横屏 **1280×800**，即便在电脑浏览器里查看也是平板效果；作业提交成功页切换为竖屏 **800×1280**。
